# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and no harassment of any kind.

## Reporting

Report unacceptable behaviour privately to the maintainer through a
[GitHub security advisory](https://github.com/nosari20/MCZ-WearOS/security/advisories/new)
(it is private to the maintainers) or by contacting the maintainer through their GitHub
profile. Reports are handled confidentially.

The maintainer may remove, edit or reject comments, commits, code, issues and other
contributions that do not follow this Code of Conduct, and may ban contributors temporarily
or permanently.
